About this database

This database records every license exception decision made for CNCF projects, including approvals, denials, and components that need no exception because their license is already allowed. Before requesting an exception, projects should check the allowed third-party license policy (opens in new tab) and, if the license is not on the allowlist, open a license exception request (opens in new tab).
